
# `obs-studio-node` 完整使用指南

## 1. 项目概述

`obs-studio-node` 是 Streamlabs 开发的 Node.js/Electron OBS Studio 封装库，版本 **0.3.21**，基于 **libobs 31.1.2sl17**。

### 架构

```
Electron Main Process
  │
  ├─ obs_studio_client.node  (Node.js 原生 C++ addon)
  │     │
  │     └─ lib-streamlabs-ipc ──── IPC 通信 ────┐
  │                                              │
  └──────────────────────────────────────────────┤
                                                 │
OBS Child Process (自动启动)                      │
  └─ obs64.exe ── libobs (OBS 引擎)             │
       ├─ obs.dll / libobs-*.dll                  │
       ├─ obs-plugins/64bit/ (插件)               │
       └─ data/ (效果文件)                         │
```

**核心设计**：双进程隔离。addon 在主进程工作，OBS 引擎在独立子进程运行，通过 IPC 通信。OBS 崩溃不会影响主进程稳定性。

## 3. 在你的 Electron 项目中集成

### 3.1 复制到项目

将整个 `obs-studio-node/` 目录复制到你的 Electron 项目中，建议放在 `native/obs-studio-node/`。

### 3.2 版本要求

| 依赖     | 版本                                     |
| -------- | ---------------------------------------- |
| Electron | **29.x**（与编译时的 iojs v29.4.3 匹配） |
| Node.js  | **20.x**                                 |
| 操作系统 | Windows 10+ x64                          |

### 3.3 引用方式

```js
// 在 Electron 主进程中
const osn = require('path/to/obs-studio-node')

// TypeScript
import * as osn from 'path/to/obs-studio-node'
```

## 4. 初始化与生命周期

### 4.1 完整示例

```js
const osn = require('./obs-studio-node')

// 1. 启动 OBS 服务进程
const pipeName = 'my-app-pipe-' + Math.random().toString(36).slice(2)
const exitCode = osn.NodeObs.IPC.host(pipeName)

if (exitCode !== osn.EVideoCodes.Success) {
    throw new Error(`OBS IPC host failed with code ${exitCode}`)
}

// 2. 设置工作目录（obs64.exe 等文件所在目录）
osn.NodeObs.SetWorkingDirectory(__dirname)

// 3. 初始化 OBS API
const initResult = osn.NodeObs.OBS_API_initAPI(
    'en-US',                 // locale
    __dirname,               // OBS 数据路径
    '1.0.0',                 // 应用版本号
    ''                       // crash 报告服务器 (空=禁用)
)

if (initResult !== osn.EVideoCodes.Success) {
    throw new Error(`OBS init failed with code ${initResult}`)
}

// 4. 使用 OSN API ...

// 5. 关闭时
osn.NodeObs.OBS_service_removeCallback()
osn.NodeObs.IPC.disconnect()
```

### 5.4 视频 API (`osn.Video` / `osn.VideoFactory`)

```js
// 创建视频上下文
const video = osn.VideoFactory.create()

// IVideoInfo 接口
interface IVideoInfo {
    fpsNum: number          // FPS 分子 (如 30)
    fpsDen: number          // FPS 分母 (如 1 → 30fps)
    baseWidth: number       // 基础画布宽度
    baseHeight: number      // 基础画布高度
    outputWidth: number     // 输出宽度
    outputHeight: number    // 输出高度
    outputFormat: EVideoFormat // 输出格式 (通常 NV12)
    colorspace: EColorSpace
    range: ERangeType
    scaleType: EScaleType
    fpsType: EFPSType
}

// 设置（触发完整重配置）
video.video = videoInfo

// 设置（仅更新旧版设置，不会立即生效）
video.legacySettings = videoInfo

// 只读
video.skippedFrames: number
video.encodedFrames: number

video.destroy()
```

**典型用法：**
```js
const video = osn.VideoFactory.create()
video.video = {

    fpsDen: 1,
    baseWidth: 1920,
    baseHeight: 1080,
    outputWidth: 1920,
    outputHeight: 1080,
    outputFormat: osn.EVideoFormat.NV12,
    colorspace: osn.EColorSpace.CS709,
    range: osn.ERangeType.Partial,
    scaleType: osn.EScaleType.Bicubic,
```

## 6. Electron 集成架构

### 6.1 主进程 (main.js)

```js
const { app, BrowserWindow, ipcMain } = require('electron')
const path = require('path')
const osn = require('./obs-studio-node')

let mainWindow
let currentScene
let currentRecording

// ---- OBS 初始化 ----
function initOBS() {
    const pipeName = 'my-app-' + Date.now()
    const exitCode = osn.NodeObs.IPC.host(pipeName)
    if (exitCode !== 0) throw new Error('IPC host failed')

    osn.NodeObs.SetWorkingDirectory(path.join(__dirname, 'obs-studio-node'))
    const result = osn.NodeObs.OBS_API_initAPI('en-US', path.join(__dirname, 'obs-studio-node'), '1.0.0', '')
    if (result !== 0) throw new Error('OBS init failed')
}

// ---- 创建窗口 ----
function createWindow() {
    mainWindow = new BrowserWindow({
        width: 1280, height: 720,
        webPreferences: {
            preload: path.join(__dirname, 'preload.js'),
        }
    })
    mainWindow.loadFile('index.html')
}

// ---- IPC 处理 ----
ipcMain.handle('obs:getSourceTypes', () => osn.InputFactory.types())

ipcMain.handle('obs:createScene', (_, name) => {
    currentScene = osn.SceneFactory.create(name)
    return { name: currentScene.name, id: currentScene.id }
})

ipcMain.handle('obs:addSource', (_, sourceType, sourceName, settings) => {
    const input = osn.InputFactory.create(sourceType, sourceName, settings)
    const item = currentScene.add(input)
    return { id: item.id, name: input.name }
})

ipcMain.handle('obs:startRecording', (_, filePath) => {
    const recording = osn.SimpleRecordingFactory.create()
    recording.path = filePath
    recording.format = osn.ERecordingFormat.MP4
    recording.quality = osn.ERecordingQuality.HighQuality

    const ve = osn.VideoEncoderFactory.create('obs_nvenc_h264', 'NVENC')
    recording.videoEncoder = ve
    const ae = osn.AudioEncoderFactory.create('ffmpeg_aac', 'AAC')
    ae.bitrate = 192
    recording.audioEncoder = ae

    recording.start()
    currentRecording = recording
    return true
})

ipcMain.handle('obs:stopRecording', () => {
    if (currentRecording) {
        currentRecording.stop()
        osn.SimpleRecordingFactory.destroy(currentRecording)
        currentRecording = null
    }
    return true
})

ipcMain.handle('obs:getStats', () => ({
    fps: osn.Global.currentFrameRate,
    cpu: osn.Global.cpuPercentage,
    memory: osn.Global.memoryUsage,
}))

// ---- 生命周期 ----
app.whenReady().then(() => {
    initOBS()
    createWindow()
})

app.on('window-all-closed', () => {
    osn.NodeObs.OBS_service_removeCallback()
    osn.NodeObs.IPC.disconnect()
    app.quit()
})
```

## 7. 关键路径说明

`module.ts` 中的路径常量全部基于 `__dirname`（即 `obs_studio_client.node` 所在目录）：

```
obs-studio-node/              ← __dirname = DefaultBinPath
├── obs_studio_client.node
├── obs64.exe
├── *.dll                     ← OBS 核心 DLL
├── data/                     ← DefaultDataPath
│   ├── libobs/               ← 着色器效果文件
│   └── obs-plugins/
├── obs-plugins/
│   └── 64bit/                ← DefaultPluginPath
│       └── *.dll             ← OBS 插件
└── resources/
```

**这要求所有文件必须与 `.node` 在同一目录下**，否则 `obs64.exe` 启动时找不到依赖 DLL。

## 9. 注意事项

1. **只能在主进程中使用**：`obs_studio_client.node` 是原生 C++ addon，渲染进程无法加载
2. **Electron 版本锁定**：编译使用 Electron 29.4.3 的 headers，需匹配 Electron 29.x
3. **路径必须一致**：所有 DLL、插件、data 必须与 `.node` 文件同目录
4. **管理员权限**：游戏捕获 (`game_capture`) 可能需要以管理员身份运行
5. **GPU 要求**：OBS 需要支持 Direct3D 11 的 GPU
6. **多实例**：同一时间只能运行一个 OBS 实例
7. **内存管理**：使用完的 Source/Scene 等对象需调用 `.release()` 或 `.remove()` 释放
8. **IPC 进程**：`obs64.exe` 由 addon 自动管理，无需手动启动/停止
