# ScreenSh 2.4.0 频道服务器

本版本配套客户端 1.4.0。客户端和服务器需一起升级，以使用重名检测及服务器密码。原 2.0.0 状态文件可直接沿用。

## 1Panel / Docker 部署

1. 将整个服务端发布包解压到服务器固定目录，保留 Dockerfile、server.js、easytier-peers.cjs、package.json、package-lock.json、compose.yaml 和 .dockerignore。
2. 在 1Panel 编排中使用该目录下 compose.yaml，构建并启动。或在该目录执行 `docker compose up -d --build`。
3. 若旧服务器已占用 3000 端口，先停止旧编排再启动新版；不要同时占用同一端口。
4. 反向代理继续指向可达的 HTTP 3000 端口，启用 WebSocket。通过域名访问 `/health` 应看到 `protocol: 2`。
5. 首次启动后，由希望成为房主的人先填写名称并连接；仅检测连通性不会占用房主身份。

本机未实际构建 Linux Docker 镜像，需在服务器上完成构建。镜像和 npm 下载均需服务器网络可达。

## 数据与权限

- 一台服务器只有一个房间，初始有主频道。创建的频道、房主和管理员在重启后保留。
- 数据保存在 `/app/data/server-state.json`，compose 使用命名卷持久化。更新时沿用同一个编排项目和数据卷，勿执行 `docker compose down -v`。
- 若通过已有编排升级，必须为 `/app/data` 添加固定数据卷，Dockerfile 中的匿名卷不能代替稳定的部署挂载。
- 本地直接运行：`npm ci --omit=dev` 后 `npm start`，状态默认保存到 `server/data/server-state.json`。
- 第一位成功进入的成员成为房主。房主可任命/取消管理员；房主和管理员能创建频道。退出不会自动转让房主。
- 名称仅用于显示，不能靠相同名称冒充房主。客户端另保存每个服务器地址对应的随机身份凭据，服务端只保存凭据摘要。
- 保留客户端 Local Storage 及服务器数据卷；清理客户端数据、换电脑或换服务器地址后不会自动恢复原角色。凭据备份需保密。
- 若房主凭据丢失，服务器维护者可停服、备份状态文件，将其中的 owner 改为 null，重新启动并由指定房主首先连接。不要在运行中编辑状态文件。
- 同一服务器的在线成员名称不能重复，跨频道同样检查；忽略首尾空格、大小写及全角/半角差异。离线后名称释放，名称不是身份凭据。
- 房主可在房间「服务器设置 → 连接密码」设置、修改或取消密码；管理员不能修改。默认无密码，启用后连接时弹窗输入，房主重连也需输入。已在线成员不受修改影响。
- 密码仅以随机盐和 scrypt 摘要保存在状态文件，重启后保留，客户端不保存密码。公网部署应使用 HTTPS，避免密码在传输中明文暴露。忘记密码时维护者可停服、备份状态文件并将 password 改为 null 后重启。
- 频道标题右侧加号可创建频道；房主和管理员可右键删除非主频道，原频道成员自动返回主频道并停止共享。
- 成员列表右键可管理权限：仅房主任免管理员；房主可踢管理员或成员，管理员只能踢普通成员。踢出仅断开本次连接，不是永久封禁，成员可重新连接。
- 未加入个人账号密码或永久封禁功能。

## 频道行为

每次连接默认进入主频道。切换频道会先停止本机共享和观看，切换失败会保留原频道。频道内展示本频道成员的共享卡片，侧栏展示服务器全体在线成员及所在频道。

频道是产品内的成员和观看分组，不是网络安全隔离：媒体仍通过当前服务器对应的 EasyTier 网络和 MediaMTX 传输。服务器密码验证信令加入权限，并不代替 EasyTier 或媒体端点的独立鉴权；私密频道或严格媒体授权需要后续单独实现。

## 服务器统一组网节点

房间顶部「服务器设置」仅房主可见，其中包含组网节点和连接密码配置。节点保存在状态文件的 easytierPeers 数组中，客户端连接时读取，不再使用本地节点设置或提供本地节点测试入口。支持最多 32 行 TCP / UDP 节点；未写协议默认 TCP。

旧状态文件首次启动新版时自动补充默认节点：hhh.591.world:11010、6.rn1.me:11010、frp-run.com:11012。更新时保留数据卷。节点修改在下次连接时生效，不主动中断在线共享；希望全部使用新节点时请成员重新连接。若节点误配置导致房主也无法组网，维护者可停服、备份并修正状态文件的 easytierPeers 数组后重启。

此版本必须配套客户端 1.4.0 或之后兼容版本；旧客户端因未使用服务器下发的节点将无法加入。

观看页返回按钮右侧显示当前这路共享的观众名称。客户端媒体连接成功后报告观看状态；返回、断线、切换频道和停止共享会移除记录，本地预览不计入观众。共享参数在顶部「共享设置」中调整。
