# ScreenSh 1.5.0

- 聊天输入框支持多选、连续粘贴和拖入图片、GIF、WebP 及其他文件，每个附件均可预览或移除。
- 一条消息可包含文字及最多 32 个附件，图片以网格展示。所有附件上传完成后一次发布；取消或失败保留整条草稿，重试避免重复消息。
- 多附件消息支持独立图片查看、文件下载、MP4 封面和播放。撤回整条消息时同步删除所有附件缓存；服务器普通清理仍保留用户本地记录。
- 系统设置新增 EasyTier 高级设置，提供 19 项选项及说明，支持本机保存和恢复默认，下次连接生效。无 TUN 模式因当前媒体链路依赖虚拟网卡而保持不可用。
- 新增“尝试启用 IPv6”：尝试启用当前活动物理网卡的 IPv6，显示协议、地址获取和公网连通检测结果，提示系统策略或 EasyTier 配置冲突。
- 自动 P2P 直连优先尝试 UDP，保留 TCP 和中转回退；不改写已配置的初始节点 URL。
- 成员网络信息增加路由和协议列，显示本机、P2P、中转跳数及 TCP/UDP/IPv6 隧道类型。收紧列间距，单行省略长内容，支持悬停查看。

本版本客户端为 **Windows 10/11 x64**。安装包已包含新增的 EasyTier 管理工具。

配套服务端版本为 **2.6.0**。多附件消息需要同步更新客户端与服务端，至少部署新的 `server/server.js`、`server/chat-store.cjs` 及配套依赖清单；Docker 部署请重新构建镜像并保留原数据卷。旧聊天记录无需手动迁移，下载和视频请求继续通过 `/chat-files/`，反向代理应支持 HTTP Range。

20 MB 以内的支持格式图片保留原始动画并直接预览；更大的图片作为文件发送。整条消息受服务器聊天存储容量上限约束。IPv6 是否可用、UDP 是否能直连取决于路由器、运营商及对端配置，无法保证所有网络均使用 UDP。

本次发布标签为 `1.5.0`；仓库原有的未发布历史标签 `v1.5.0` 保留不变。
