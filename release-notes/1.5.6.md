# ScreenSh 1.5.6

- 自动更新改为启动前执行：开启时先检查最新版、下载并安装，成功后再进入软件；关闭时直接进入软件，可在设置中手动更新。主界面运行期间不再定时检查或自动后台下载。
- 新增独立更新界面，跟随软件的浅色 / 深色主题，显示下载进度、数据量和版本，失败时提供重试及进入当前版本的入口。
- 新增独立安装向导，使用固定浅色界面，提供安装位置选择、安装进度及完成后启动；精简单行路径输入框和按钮样式，保留自动更新的静默安装方式。
- 安装阶段交由独立进程接管，等待主程序退出后再运行安装器，记录真实返回码并核对安装后的版本，成功后自动重启软件。
- 修正安装器进程筛选范围，排除自身及 data 下的更新程序；安装时使用安装目录外的已校验临时副本和临时目录，兼容旧版卸载器，避免更新程序被误判为旧客户端而关闭。
- 新版界面成功启动后，校验并保留新安装包作为下次差分更新的基础，清理旧包与多余待安装文件。校验失败或未来版本缓存保持保留。
- 保留启动失败提示、启动日志及安装日志，防止安装未完成时反复静默退出。
- 软件功能介绍统一放在 README，精简服务器与视频转发部署教程，清理开发过程文档和旧版本本地说明。

本次已重新打包并替换 1.5.6 发布文件。已安装早期 1.5.6 的用户需要下载安装包覆盖安装，同版本不会触发自动升级。安装前退出客户端，保留原安装目录的 data 文件夹。
