# ScreenSh 1.5.9

- 优化客户端入服速度，缩短 EasyTier 就绪检测的等待时间。
- 按分辨率和帧率推荐屏幕共享码率，增加 AV1 硬件编码选项，完善 AMD 编码和低延迟播放处理。
- 改进聊天布局和消息操作。部署新版服务端后，服主可撤回自己及其他成员的历史消息。
- 新增同版本构建号更新。安装 1.5.9 后，后续修复可沿用 1.5.9 版本号并通过更高的构建号更新。

## 更新方式

- 已启用自动更新的客户端可在下次启动时检查更新，也可从软件设置手动检查。
- 同版本修复支持差分下载和退出后替换程序文件。差分条件不满足时可下载完整更新包。正式版本仍提供 Windows 安装包和服务端部署包。
- 如果 1.5.6 的旧更新器无法启动安装程序，请退出客户端后使用本版安装包覆盖安装，保留原安装目录和 `data` 文件夹。
