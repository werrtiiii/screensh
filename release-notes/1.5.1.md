# ScreenSh 1.5.1

- EasyTier 高级设置开放“无 TUN 模式”，默认关闭；保存后重新连接服务器生效。不创建系统虚拟网卡，通过本地 TCP/UDP 转发支持频道语音、屏幕共享、共享预览和 lolPing。
- 支持 TUN 与无 TUN 客户端混用。修复无 TUN 转发改变 UDP 源端口后，TUN 一方无法接收 lolPing 的问题，保留加密认证、频道隔离和防重放检查。
- 改进频道退出、媒体会话结束及服务器重连时的转发清理，并兼容内置 EasyTier 在全部媒体转发结束后无法重新建立转发的情况。
- 无 TUN 模式通过管理接口判断网络就绪；成员网络信息使用 EasyTier 报告的直连延迟，无可靠结果时显示“—”。

已验证三成员无 TUN 语音，以及 TUN/无 TUN 混用时双向音频解码、双向屏幕共享、各自预览、加密 lolPing 和转发清理；147 项单元测试通过。原生互通测试使用本机独立网络实例，尚未覆盖所有公网 NAT 和防火墙环境。

本版本适用于 **Windows 10/11 x64**，服务端无需因本次更新更换，继续使用 **2.6.0**。双方建议更新至 1.5.1，以获得混用时的 lolPing 接收兼容修复。

无 TUN 模式仍保留 UDP 媒体传输，会增加本机转发开销；客户端仍按现有权限清单要求管理员启动。
