# ScreenSh 1.4.15

- 新增服务器文字聊天：频道外显示完整聊天区，频道内位于卡面下方，可拖动调整高度并至少保留一行卡面。
- 支持文字格式、表情、网页链接、图片、GIF、WebP 和任意文件附件。图片按实际内容识别，修复扩展名错误导致动图无法发送的问题。
- 文件与图片支持分片上传、进度显示和取消上传；附件大小受服务器聊天存储上限限制，20 MB 以内的支持格式图片直接预览。
- MP4 支持封面预览与点击播放，可暂停、拖动进度和全屏，保留下载入口。仅缓存静态封面，不自动下载完整视频。
- 服务端和本地独立保存聊天记录，可分别设置保存天数、容量和清理。服务器普通清理不删除本地已保存的消息和图片。
- 支持撤回自己两分钟内的消息；高权限成员可撤回权限更低成员的消息。撤回同步服务器及客户端聊天记录，离线客户端重连后同步。
- 同一人连续消息合并显示头像和名称，显示日期与时分，后续消息悬停显示左侧时间。Enter 发送，Shift+Enter 换行，并兼容中文输入法。
- 新增临时频道与持久频道、频道密码及权限管理；临时频道无人五分钟后自动删除，显示临时及加锁标识。
- 频道和服务器成员名称单行省略；频道列表支持滚动，单频道超过十人时启用独立成员滚动，并保留更新前的滚动位置。
- lolPing 移入系统设置，未加入服务器也可在本机使用，进入频道后与同频道成员共享。成员角色仅显示图标，支持离线成员管理员权限管理。
- 优化共享与观看入口、成员网络按钮位置、聊天输入区、设置说明和列表头像缩略图，更新软件图标。
- 服务器地址可省略协议和端口，默认地址连接失败后再尝试 31012 端口，输入与书签保留原地址；同一服务器的多个域名共用身份。
- 服务器成员列表下显示用户数、频道数、运行时间、创建时间及当前时间，缺少创建时间的旧数据自动初始化并持久保存。

配套频道服务端版本为 **2.5.0**。请同步更新客户端和服务端，并将新增的 `server/chat-store.cjs` 一同部署。Docker 部署需要重新构建镜像，保留原数据卷。反向代理需转发 `/chat-files/`，并支持视频播放所需的 HTTP Range 请求。

普通服务器历史清理保留用户本地记录；消息撤回则同步删除客户端对应记录。已手动下载到系统文件夹的副本不受影响。客户端仅在查看附近时加载图片与视频封面，普通附件需点击下载。

lolPing 源码遵循随附 MIT 许可；相关图像和音效素材权属见安装包内 `lolping/NOTICE.md`。
