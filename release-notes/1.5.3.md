# ScreenSh 1.5.3

- 新增「外部 OBS」共享源：连接本机 OBS WebSocket 后，可在软件内开始、停止推流，并预览当前场景。画面和声音沿用 OBS 配置，通过本地 MediaMTX 提供给观看者；正常停止后恢复原推流设置。
- 新增默认开启的自动更新开关：后台检查、下载新版本，下次启动时优先校验并安装本地已下载的更新包。退出软件时不安装，保留手动检查和立即安装。
- 无 TUN 模式新增 UDP 往返延迟探测，relay 中继路由也能显示到成员的实际延迟。P2P 保留原有隧道统计，探测通道自动释放。
- 修复网卡掉线后重连时，旧会话尚未超时导致误报「名称已被使用」的问题。
- 简化外部 OBS 页面的文字说明，将推流设置说明收纳至问号提示。

178 项测试通过，另有 1 项因缺少 TUN 测试网卡跳过。已验证本地真实 EasyTier `relay(2)` 路由的 UDP 延迟探测、MediaMTX 的 WHIP 接收及 WHEP 视频播放，以及本地更新包校验和更新设置流程。OBS 控制端使用 WebSocket 协议模拟服务，尚未覆盖用户安装的 OBS Studio 和所有公网网络环境。

适用于 **Windows 10/11 x64**。无 TUN 中继延迟探测需双方使用新版客户端；旧版仍可连接，但可能不响应探测。服务端继续使用 **2.6.0**，无需更新服务端。
