# ScreenSh 1.5.5

- 新增房主可配置的外部 MediaMTX 转发，支持 EasyTier 组网及直连服务器 WHIP/WHEP 两种方式；启用转发时客户端不启动本地 MediaMTX。
- 支持配置 EasyTier 网络名称、密码及转发节点，组网参数在下次进入服务器时生效；关闭服务器转发后同步关闭客户端的转发选择。
- 调整共享启动、停止和异常恢复流程，将内置 OBS 操作放入独立进程，减少界面阻塞及停止共享等待。
- 改善无 TUN 模式的媒体转发突发承载能力，独立使用 UDP 缓冲补丁核心；TUN 模式保留原版核心。实际效果仍取决于网络带宽、丢包和服务器配置。
- 完善混合 TUN/无 TUN 场景的成员延迟检测及媒体会话清理。
- 配置、本机聊天缓存、更新包等改为保存在安装目录的 `data` 文件夹。首次启动复制原数据，旧位置保留备份；升级及卸载保留 `data`。
- 精简安装包语言资源，只保留中文和英文。

服务器相关功能需同步更新服务端。服务端压缩包包含 Docker 部署文件及两种 MediaMTX 转发配置模板；MediaMTX、EasyTier 仍由房主独立运行。直连转发需开放媒体端口并配置客户端可达的 ICE 地址，详细步骤见压缩包中的《视频流转发部署》。

已完成针对性功能验证、本机真实 OBS/MediaMTX/WebRTC 推拉流验证、数据迁移及安装器数据保留验证；不代表所有公网/NAS 网络均已验证。
