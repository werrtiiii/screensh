# ScreenSh 1.5.2

- 增加 Windows 语音计时保护，改善后台或屏幕共享期间音频采样、发包节奏变慢，导致接收码率下降和语音断续的问题。仅处理本软件及其子进程，结束语音时恢复原有策略，不修改系统全局设置。
- 优化无 TUN 媒体转发：移除逐包枚举网卡的开销，扩大 UDP 缓冲；共享端使用原生平滑发包，减少关键帧突发和分片引起的丢包、卡顿。
- 提高语音发送优先级，保留 Opus 自适应码率和 UDP 媒体传输。
- 扩充语音诊断，显示双向码率与包速率、发送排队、接收丢包、丢包补偿及缓冲目标，方便定位采集、传输和播放异常。

156 项测试通过。本机 UDP6 混合模式下，两个共享方向分别完成无人观看和有人观看各一分钟的同时语音测试；稳定阶段接收缓冲低于 68 ms，未出现丢包补偿。原生测试使用本机独立 EasyTier 实例和合成音频，尚不能覆盖所有公网链路、真实麦克风和驱动环境；共享初始化仍可能短暂停顿。

适用于 **Windows 10/11 x64**。建议双方更新并完全退出旧进程后重新启动；服务端继续使用 **2.6.0**，本次无需更新服务端。
