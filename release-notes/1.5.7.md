# ScreenSh 1.5.7

- 新增免安装差分更新，复用本地文件，按块下载变化内容，更新时保留 `data` 和个人配置。
- 新增完整安装包备用更新入口，按需获取安装包，正常差分和免安装更新不额外下载 EXE。
- 更新来源统一为 GitHub；开启加速时，版本检查、校验信息及下载优先使用选定加速源，再回退直连。
- 安装、更新和系统配置操作改用独立 Windows 程序，不再依赖 PowerShell。
- 完善更新缓存、临时安装副本及 OBS 隔离运行文件的自动清理，减少磁盘占用。
- 优化屏幕共享编码、接收缓冲及无 TUN 媒体发送队列；新用户默认共享帧率调整为 60 FPS，已有设置保持不变。
- 调试面板新增实际解码器、接收缓冲、解码耗时、本机编码器及媒体排队数据。
- 优化 EasyTier 防火墙规则管理，统一聊天界面与服务器列表的默认头像。
