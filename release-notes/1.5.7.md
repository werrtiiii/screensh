# ScreenSh 1.5.7

- 新增免安装更新：复用本地未变化的文件，按块下载变化内容；差分更新失败时回退到完整更新包。首次安装仍提供安装向导。
- 更新前校验文件，退出主程序后替换程序文件，保留安装目录中的 data 和个人配置；新版启动失败时恢复旧版本。
- 更新仅从 GitHub 获取。开启 GitHub 加速时，检查版本、获取校验信息和下载均优先使用选定加速源，失败后回退直连；关闭后直接连接 GitHub。
- 修复关闭更新窗口后下载仍继续、更新窗口退出与安装交接冲突，以及失败重试和更新缓存清理的问题。
- 更新成功后清理旧安装包、已完成的更新缓存和多余的 OBS 隔离运行文件，减少磁盘占用。
- 优化屏幕共享编码和无 TUN 媒体发送队列，修复软件编码部分场景下解码不连续的问题；新用户默认共享帧率调整为 60 FPS，已有设置保持不变。
- 请求更低的音视频接收缓冲，增加持续解码停滞检测；调试面板增加实际解码器、接收缓冲与解码耗时、本机编码器及媒体排队等数据。
- 清理本软件遗留的 EasyTier 防火墙规则，统一聊天界面的默认头像。
- 安装、更新、回滚、自启动、IPv6 检查和防火墙维护改用独立 Windows 程序，软件运行不再依赖 PowerShell。
- 修复独立更新程序退出后更新未完成的问题，补充更新启动确认、旧安装器兼容处理和中断恢复入口；保留原有 data 数据。
- 修复长路径下更新失败及更新包被占用导致缓存无法清理的问题。

从旧版升级时请保持原安装目录，以便继续使用 data 中的配置、聊天缓存及其他个人数据。首次升级到此版本，旧客户端可能仍下载安装包；升级后的客户端支持新的免安装差分更新方式。

本次更新替换了 1.5.7 的发布附件。已经安装早期 1.5.7 的用户，请下载新版安装包并覆盖安装到原目录；同版本不会触发自动更新。
