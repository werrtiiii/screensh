# ScreenSh 1.4.14

- 调整明暗主题配色，参考 lolPing Windows 设置页的中性灰与 Fluent 蓝色风格，统一按钮、卡面、频道列表、菜单和弹窗外观。
- 设置页新增分组滚动导航，补充弹窗、菜单和消息提示动效，并遵循系统的减少动画偏好。
- 共享源选择器新增程序／屏幕分类与缩略图预览，保留原有 OBS 捕获标识；自己的频道卡面新增共享入口。频道外隐藏卡面与共享按钮，并支持服务器成员列表右键交互。
- 主动退出频道时播放与退出服务器相同的音效，修复重复状态更新取消音效的问题；切换频道和断线重连保持原有音效逻辑。
- 关麦后自己的卡面不再显示“麦克风已关闭”文字；减少界面状态已明确表达的重复提示，保留必要的错误和操作提醒。
- 成员列表支持识别软件在线状态：退出服务器、停留首页或关闭到托盘后仍可在线，退出软件或连接超时后头像变灰。客户端向已保存的服务器报告状态，不接入第三方在线服务，也不加入频道或启动媒体连接。
- 优化纯语音发送链路，默认音量且无伴奏时直接发送麦克风轨道；回声消除、降噪和自动增益可独立设置，伴奏和非默认音量仍通过混音处理。
- 整理主进程、lolPing、单元测试和集成测试目录，统一打包文件清单，并修复 Docker 部署缺少 lolping-protocol.cjs 的问题。

配套频道服务端版本为 **2.4.2**。软件在线状态功能需要同步更新客户端和服务端；旧客户端仍按是否加入服务器判断在线。Docker 部署请重新构建镜像，保留原有数据目录，无需手动迁移数据。

lolPing 源码遵循随附 MIT 许可；相关图像和音效素材权属见安装包内 `lolping/NOTICE.md`。
