# ScreenSh 1.5.4

- 修复 NVIDIA NVENC、AMD AMF 等硬件编码器无法加载的问题：隔离 OBS 进程现在同时携带硬件编码探测程序，避免设备拥有独显却被误报为不支持硬件编码。
- 硬件探测程序变更后自动更新隔离进程目录，无需手动删除旧缓存。
- 发布与 OpenList 同步分为独立任务，同步在 NAS Runner 执行，并仅下载必要脚本和安装轻量依赖。
- 增加默认开启的更新下载加速设置，可选择预设源或自定义地址并测试连通性。版本与校验信息优先从 GitHub 官方获取，连接失败后使用选定加速源；安装包保留 OpenList、加速源及官方源回退。
- 移除多余的更新加速说明；共享来源切换到屏幕或外部 OBS 时保持弹窗尺寸一致，观看共享时也可打开成员 IP 信息。
- 统一 TUN 与无 TUN 的成员延迟探测，优先显示端到端 UDP 往返时间，失败时按条件回退到 ICMP 或直连隧道 RTT，并标明来源。
- 修复服务器组网节点说明被裁切的问题，新增逐项 TCP/UDP 节点握手测试及失败原因显示，避免测试进程管理端口与现有 EasyTier 冲突。

新增改动已完成相关单项检查、界面验证及本机 EasyTier TCP/UDP 握手、中转延迟探测验证；TUN/无 TUN 混合模式的新版延迟逻辑尚未双机实测。发布时不重复运行完整运行时测试，仅进行构建及发布文件检查。

适用于 Windows 10/11 x64。安装 1.5.3 的用户可以通过软件检查更新升级。此次替换同版本安装包，已安装旧版 1.5.4 的用户需要下载安装包覆盖安装。服务端继续使用 2.6.0，无需升级。
