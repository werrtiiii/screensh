# 本地数据目录

客户端将可变数据保存在 `ScreenSh.exe` 同目录的 `data` 文件夹：

| 子目录 | 内容 |
| --- | --- |
| `user-data` | 设置、服务器列表、加密保存的凭据、OBS 配置、浏览器缓存、本机聊天记录及图片缓存 |
| `updates` | 自动更新安装包、差分更新缓存和待安装信息 |
| `downloads` | 聊天附件的默认下载位置；手动选择其他保存位置时以用户选择为准 |
| `logs` | 应用日志目录 |
| `temp` | 本进程及原生子进程的临时文件 |
| `crash-dumps` | 崩溃转储 |

源码运行时使用 `app/data`。测试或显式设置的开发浏览器配置目录保持隔离，不自动迁移至正式目录。不要将个人 `data` 文件夹加入发布包。

首次启动在打开浏览器配置前复制旧用户数据目录，并迁移原 `screensh-updater` 更新缓存。复制完整成功后才启用新配置目录；已有的新配置不会被旧备份覆盖。旧位置保留备份，不自动删除；确认设置、聊天记录和更新正常后可自行清理旧位置。迁移时应完全退出旧客户端。

更新安装包和卸载程序均保留安装目录中的 `data`。重新安装到同一位置可继续使用。安装到其他目录不会自动寻找旧安装目录中的数据，迁移前应退出客户端，再将整个 `data` 文件夹复制到新位置。Windows 加密凭据仍绑定原 Windows 用户/系统，复制文件不保证能在另一用户或电脑解密。

目录不可写时会明确提示并停止启动，不会静默切回系统盘。安装版已有管理员权限声明；便携或源码运行可放在具有写权限的目录。

这里保存的是本机聊天缓存。远程 NAS/服务器的原始聊天记录仍在服务端 `data/chat`（Docker 为其映射的数据卷），不迁到客户端安装目录。系统自身生成的日志、安装器运行过程及其他外部软件的数据不受客户端目录设置控制。
