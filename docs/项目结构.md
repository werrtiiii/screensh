## 日常开发

在仓库根目录执行：

```powershell
npm run dev --prefix app
npm test --prefix app
npm test --prefix server
npm run test:ui --prefix app
npm run test:voice-ui --prefix app
npm run test:lolping --prefix app
node app/scripts/run-electron.cjs smoke-channel-ui.cjs
node app/scripts/run-electron.cjs smoke-capture-previews.cjs
node app/scripts/run-electron.cjs smoke-ui-design.cjs
node app/scripts/run-electron.cjs smoke-app-presence.cjs
npm run test:chat --prefix app
```

文字聊天：`server/chat-store.cjs` 管理服务器聊天记录、图片、保留策略与清理；数据保存于服务端数据目录的 `chat/` 下。客户端 `app/renderer/chat.js` 管理共享聊天区与交互，`chat-markup.mjs` 安全渲染文字格式，`chat-cache.mjs` 将消息和图片分开存入 IndexedDB，`chat.css` 控制频道外完整聊天与频道内卡面下方聊天的布局。

`npm test` 只运行对应 `tests/` 下的单元测试，不扫描旧安装包或第三方源码。Electron 集成测试通过启动器单独运行；测试文件位于 `app/tests/integration/`，原有命令保持有效。

## 构建与部署

```powershell
npm run pack:win --prefix app
npm run pack:portable --prefix app
```

两种客户端打包方式使用 `app/package.json` 的同一份 `build.files` 定义，避免新增或移动模块后只更新一种包。原生程序清单由 `app/scripts/package-resources.cjs` 校验；打包完成后使用 `app/scripts/check-installer.cjs` 验证安装包内容和 OBS 运行库。

服务端仍可直接在 `server/` 运行 `npm start` 或 `docker compose up -d --build`，详见 `server/部署教程.md`。单元测试目录不进入 Docker 镜像。

成员列表的在线状态由 `app/renderer/app-presence.mjs` 向已保存的服务器报告，独立于频道、语音和 EasyTier。客户端以该服务器已保存的身份登记，每15秒续期，服务端租期为45秒；短暂断开保留宽限期。退出服务器不会停止状态连接，删除书签或退出软件会停止。此功能需客户端与服务端配套更新，旧客户端仍按是否加入服务器判定在线。

不要手改 `app/lolping/dist/`、`app/dist/`、`node_modules/` 中的生成内容。应用运行数据、测试截图、旧安装包和本机开发配置保留在原位置，不混入源码目录，也不在本次整理中删除。

lolPing 在系统设置中使用统一的本机配置；升级时优先沿用已启用的旧服务器配置，旧记录仍保留。未加入频道时仅运行本机输入助手和覆盖层，进入支持 lolPing 的频道且开启房间同步后才建立 EasyTier 传输。退出服务器后恢复本机模式，真正退出软件时释放输入助手。
