# 轻量液态玻璃与动效

**目标：** 沿用现有排版与布局，在弹窗、浮层和设置选中态中加入玻璃透光、边缘高光与连续运动。

**实现：** ui.css 继续拥有材质和动效变量；ui.js 更新设置导航伪元素的位置，不重建控件。正文与输入框保留实底。只在少量浮层使用固定模糊，不动画 blur/filter，不加入持续动画或新依赖。
