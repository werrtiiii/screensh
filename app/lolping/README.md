# ScreenSh 的 lolPing 集成

每位成员在「服务器设置 → 启用 lolPing／配置」自行设置，默认关闭。配置按服务器 ID 保存在本机用户数据目录的 `lolping.json`。已连接服务器但未加入频道时，信号、表情和轮盘仅在本机显示，不创建 UDP 连接，不接收其他成员内容，也不占用文字和面板的快捷键。进入频道后自动恢复频道同步，退出频道时释放房间窗口和网络连接，再切换为本机模式。离开服务器、连接中断或关闭开关时停用输入助手和透明覆盖窗口；重连后按当前频道状态恢复。

频道就是同步房间：已开启功能的同频道成员通过 EasyTier 虚拟 IP 直接收发 UDP 标记和内置表情，位置按各自屏幕分辨率换算。标记键默认 Alt，表情键默认 Ctrl；按住键拖动并松开选择。Ctrl + Alt + P 临时暂停或恢复。普通输入仍交给底下的应用，全屏应用中默认暂停，可在配置中关闭此项。独占全屏可能覆盖桌面叠加层。

数据路径是「本机 → EasyTier 虚拟网卡 → 同频道成员」。频道服务器仅同步地址、临时 UDP 端口和 X25519 会话公钥，不转发标记、表情或音效数据。客户端仅绑定 `10.144.x.x`，不向物理局域网广播，没有 Socket.IO 或公共 Nostr 数据中继回退。每对成员按服务器、频道和会话派生 AES-256-GCM 密钥，检查来源端点及重放序号；切换频道、关闭、断线重连时释放端口并更换会话密钥。音效在接收端本地播放。EasyTier 底层仍可能使用自己的中继链路；UDP 标记不补发，网络丢包时可能少显示标记。

支持命名触发键及自定义字母、数字、功能键等按键，单按字符键在松开后输入、不连发；回车、空格、退格和导航键保留给正常输入。配置页可拖拽轮盘扇区、把信号拖到中心、点击预览及恢复默认布局。也支持拖动距离、大小、持续时间、保留最后标记、音效音量、静音及接收频率限制。

Alt + T 输入最多 120 字，Enter 发送，Esc 或点击外部取消；接收端可选择位置气泡或顶部弹幕。`/ff` 发起投降，`/noff` 投反对票，`/ready` 发起就位确认。按住 Tab 打开房间面板，松开关闭，点击名字发送「名字 - 存活」；面板提供最近 200 条本次房间记录、屏蔽指定成员、房间内容静音和投票入口。屏蔽仅影响本机 lolPing，不改变语音、频道或服务器权限；退出房间清空屏蔽和历史。

房间面板、文字输入框、投降／踢人投票和就位确认直接复用原版 lolPing 的渲染器、CSS 及素材。就位确认包含倒计时、接受过渡及等待循环、拒绝动画和原版音效；投票结束后保留最后状态 3 秒，并在覆盖层显示结果文字。投降／踢人浮窗位于主屏右侧，就位窗口居中，文字框在鼠标附近显示。关闭、暂停、离开时停止动画和声音并释放窗口。

投降需 70% 向上取整同意，就位需全部同意，踢人需除目标以外超过半数同意；投降／踢人 60 秒、就位 15 秒，没有回应按反对处理。投票使用开始时固定成员集合，离开不能降低门槛；参与成员集合不一致时忽略该提案，等待重发。UDP 文字和投票有短期重发及逻辑去重，投票结果仍为各客户端独立统计，持续丢包可能导致不同端结果不一致。踢人仅关闭被投票者的 lolPing，可自行重新开启，不会移出 ScreenSh 频道。新功能需参与者使用新版客户端。

表情、频道房间、文字、投票和面板可分别关闭；相关设置隐藏，关闭的文字／面板按键会交还其他应用。文字快捷键、面板键和暂停快捷键可配置并检查冲突。使用 ScreenSh 的连接与频道成员管理；没有独立房间码、公共 Nostr 中继、独立托盘或更新程序；尚未接入自定义表情导入。

## 构建与验证

Windows 下执行 `npm ci` 和 `npm run build:lolping`。输入助手需要支持 C++20 和线程库的 MinGW-w64；可设置 `LOLPING_CXX` 为 `g++.exe` 的绝对路径。普通 `npm start`、`npm run dev` 和现有打包命令会先构建 lolPing，首次需要编译器；之后源码未变时复用输入助手。仅构建 JS 可用 `npm run build:lolping -- --js-only`。

生成的 JS、预加载和素材在 `dist/`；输入助手在 `../res/lolping-hook-helper.exe`，由既有 extraResources 规则打进安装包。没有在仓库中保存第二套 Electron，也不启动另一个 lolPing 应用。

`npm test` 覆盖配置、频道转换、UDP 加密／重放／密钥更新和资源释放；存在本机 EasyTier 网卡时额外验证实际虚拟 IP 绑定与收发。`npm run test:lolping` 使用两个真实 Electron 页面、透明覆盖层、项目服务器、真实 UDP 和输入助手模拟协议验证标记与表情全链路；测试通过专用注入选项允许回环地址，不注入用户鼠标键盘。真实 Windows 钩子的启停另行验证。这些本机测试不代表跨两台电脑的 EasyTier 隧道、所有游戏及多显示器硬件组合均已实测。

客户端和服务器需一起更新，服务端部署 `server.js` 与 `lolping-protocol.cjs`；不再需要旧版 `lolping-catalog.json`。能力标识为 `easytier-udp-v1`，旧服务器不会启动本功能；客户端会提示更新。服务端校验端口、公钥和当前频道，在频道切换或删除时清空端点。客户端按已验证的同频道成员列表收发，并核验标记类型、屏幕号、坐标与频率。没有数据库迁移。
